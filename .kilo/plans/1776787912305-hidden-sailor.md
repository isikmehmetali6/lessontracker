### 1. Notes Tablosu Schema Hatası — `drawingData` Sütunu Eksik

**Dosya:** `lib/core/database/database_helper.dart`
**Satır:** 123-142

**Problem:** `CREATE TABLE notes` ifadesinde `drawingData`, `cloudPath`, `thumbnailCloudPath` sütunları eksik. Bu yüzden `INSERT OR REPLACE` hatası veriyor.

**Çözüm:**
```sql
-- Mevcut (eksik):
CREATE TABLE notes (
  id TEXT PRIMARY KEY,
  courseId TEXT NOT NULL,
  type TEXT NOT NULL,
  title TEXT NOT NULL,
  content TEXT,
  filePath TEXT,
  thumbnailPath TEXT,
  audioDuration INTEGER,
  tags TEXT,
  bookmarks TEXT,
  isBookmarked INTEGER DEFAULT 0,
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL,
  searchContent TEXT
  -- drawingData, cloudPath, thumbnailCloudPath EKSİK!
)

-- Olması gereken:
CREATE TABLE notes (
  id TEXT PRIMARY KEY,
  courseId TEXT NOT NULL,
  type TEXT NOT NULL,
  title TEXT NOT NULL,
  content TEXT,
  filePath TEXT,
  thumbnailPath TEXT,
  audioDuration INTEGER,
  tags TEXT,
  bookmarks TEXT,
  isBookmarked INTEGER DEFAULT 0,
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL,
  searchContent TEXT,
  drawingData TEXT,
  cloudPath TEXT,
  thumbnailCloudPath TEXT
)
```

**Değişiklikler:**
1. `database_helper.dart` satır 123-142: `CREATE TABLE notes` ifadesine eksik sütunları ekle
2. Migration v15 ve v17'yi kontrol et, eksik ALTER TABLE komutlarını tamamla

### 5. MoodleProvider Race Condition

**Dosya:** `lib/providers/moodle_provider.dart`
**Satır:** 281, 293

**Problem:** `_syncAll` ve `_syncAccount` aynı anda çalışabilir.

**Çözüm:**
```dart
// Sync flag ekle
bool _isSyncing = false;

Future<void> _syncAll({bool silent = false}) async {
  if (_isSyncing) return; // Zaten syncing
  _isSyncing = true;
  try {
    for (final account in _accounts) {
      await _syncAccount(account.id, silent: silent);
    }
  } finally {
    _isSyncing = false;
  }
}
```
